Olympus 0.1.0-rc.1
A Zeus Poseidon open source remake project.
A fork of eZeus, an open-source implementation of Zeus: Master of Olympus and
the Poseidon expansion.

To play Olympus you need the original game (Zeus: Master of Olympus base game +
Poseidon expansion). English and Polish versions only (font glyph limits).

This build ships NO original game data. All graphics, sounds and text are read
at runtime from your own installed copy of the game.

INSTALL
1. Extract this zip into your game directory, e.g.
   (...)/Zeus and Poseidon/Olympus-0.1.0-rc.1
2. Install VC_redist.x64.exe (only if Olympus.exe fails to start).
3. Run Bin/Olympus.exe.

If the game data is not found, create Bin/zeus_path.txt containing the relative
path from the exe to your Zeus and Poseidon folder.
